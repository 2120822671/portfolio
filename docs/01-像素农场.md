# 01 · 像素农场 Online

> 在线休闲农场经营游戏。作物种植、动物养殖、商店经济、每日任务与排行榜构成完整养成循环。

- **前缀**：`/farm/`
- **代码位置**：`apps/farm/`
- **技术栈**：FastAPI · SQLAlchemy 2.0（异步）· SQLite（aiosqlite）· JWT（python-jose + passlib）· Pydantic v2 · pydantic-settings

## 功能模块

| 模块 | 说明 |
|------|------|
| 认证 | 注册 / 登录 / 当前用户信息，JWT Bearer Token |
| 农场 | 土地列表、播种、收获、清理枯萎、扩建土地；服务端返回生长剩余秒数 |
| 动物 | 购买动物、喂养、产出计时、采集产物 |
| 商店 | 种子 / 动物 / 工具分类商品、购买、出售背包产物 |
| 背包 | 物品列表、数量、可售单价 |
| 每日任务 | 任务进度、领取奖励、登录签到奖励 |
| 排行榜 | 财富榜（金币 + 仓库价值） |
| 管理后台 | 管理员账号数据维护 |

## 目录结构

```
apps/farm/
├── app/
│   ├── main.py          # 应用入口、路由注册、异常处理
│   ├── config.py        # pydantic-settings 配置
│   ├── database.py      # 异步引擎 / 会话 / 建表
│   ├── models/          # user / farm / crop / animal / shop / inventory / task
│   ├── routers/         # auth / farm / animals / shop / inventory / tasks / rank / admin
│   ├── schemas/         # 请求 / 响应模型
│   ├── services/        # 农场、产出、每日任务业务逻辑
│   └── utils/           # 安全（JWT / 密码）、时间工具
├── frontend/            # index.html + css/style.css + js/app.js
├── scripts/seed_data.py # 种子数据（作物 / 动物 / 商店 / 管理员）
└── pixel_farm.db        # SQLite 数据文件（首次启动生成）
```

## 接口分组

所有接口统一在 `/farm/api/v1` 下：

- `POST /auth/register`、`POST /auth/login`、`GET /auth/me`、`PUT /auth/profile`
- `GET /farm/`、`POST /farm/plant`、`POST /farm/harvest`、`POST /farm/clear/{cell_index}`、`POST /farm/expand`
- `GET /animals/`、`POST /animals/feed`、`POST /animals/collect/{animal_id}`、`DELETE /animals/{animal_id}`
- `GET /shop/items`、`POST /shop/buy`、`POST /shop/sell`
- `GET /inventory/`
- `GET /tasks/daily`、`POST /tasks/claim/{task_type}`
- `GET /rank/wealth`、`GET /rank/weekly-harvest`
- `GET /admin/stats`、`GET /admin/users`、`POST /admin/users/{id}/ban`、`POST /admin/users/{id}/unban`
- `GET|POST /admin/crops`、`GET|POST /admin/animals`、`GET|POST /admin/shop`（含 PUT / DELETE 维护）

## 运行说明

- 数据库连接由聚合入口注入：`sqlite+aiosqlite:///apps/farm/pixel_farm.db`
- 建表与种子数据在聚合入口的 startup 中手动执行（挂载子应用的 lifespan 不会自动触发）
- 默认管理员：`admin / admin123`（`app/config.py` 可改）
- 前端倒计时在浏览器本地递减，每 30 秒或操作后与后端同步一次
