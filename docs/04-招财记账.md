# 04 · 招财记账（个人记账系统）

> 单页个人记账系统。多账本、收支流水、周期账单、预算看板与大模型意图解析，配招财猫与木鱼等轻量交互。

- **前缀**：`/account/`
- **代码位置**：`apps/account/`
- **技术栈**：FastAPI · PyMySQL · MySQL 8.0 · APScheduler · Canvas 原生绘图 · LLM 意图解析（带规则兜底）· 原生 JS 单页应用

## 功能模块

| 模块 | 说明 |
|------|------|
| 账本 | 多账本创建 / 切换 / 归档 |
| 流水 | 收入 / 支出记账、编辑、删除、按账本与时间筛选、分页 |
| 统计 | 汇总余额、收支合计、分类占比、月度趋势看板 |
| 预算 | 分类预算设置与超支提醒 |
| 周期账单 | 每日 / 每周 / 每月自动入账，由 APScheduler 调度 |
| 智能解析 | 自然语言记账（如“早餐花了 12 元”），LLM 解析 + 关键词规则兜底 |
| 日报与打卡 | 每日日报生成、连续打卡与成就 |
| 交互彩蛋 | 招财猫 SVG 动画、木鱼点击反馈 |

## 接口分组

统一在 `/account/api/...` 下：

- `records`：列表分页、新增、更新、删除、汇总 `summary`
- `books`：账本列表、创建、切换
- `budget`：预算查询与设置
- `stats`：分类统计、趋势数据
- `intent`：自然语言解析记账
- `automation`：周期账单、日报、打卡

## 运行说明

- 数据库：`account_db`，执行 `apps/account/建表SQL.sql` 初始化
- 大模型为可选能力：未配置密钥时自动使用规则解析，不影响记账主流程
- 周期账单调度由聚合入口的 APScheduler 实例统一驱动
- 入口页面：`/account/`
