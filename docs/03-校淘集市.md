# 03 · 校淘集市（二手交易平台）

> 校园二手交易完整闭环。从发布审核、加购下单、模拟支付到超时关单与举报风控，并配备管理员后台与统计看板。

- **前缀**：`/secondhand/`
- **代码位置**：`apps/secondhand/`
- **技术栈**：FastAPI · SQLAlchemy 2.0 · MySQL 8.0 · Redis（风控 / 缓存，可降级）· APScheduler · JWT · 原生 JS

## 功能模块

| 模块 | 说明 |
|------|------|
| 认证 | 注册 / 登录，JWT 鉴权，管理员角色区分 |
| 商品 | 发布（图片上传）、列表筛选排序、详情、编辑、上下架 |
| 购物车 | 加购、改数量、删除、结算 |
| 订单 | 下单、模拟支付、取消、确认收货、超时自动关单 |
| 收藏 | 收藏 / 取消收藏、收藏数统计 |
| 聊天 | 买卖双方会话与消息、议价 |
| 举报 | 举报商品 / 用户，Redis 去重与频率限制 |
| 管理后台 | 商品审核、用户管理、举报处理、运营统计 |

## 目录结构

```
apps/secondhand/

│   ├── routers/              # auth goods cart order favorite chat report upload admin admin_manage
```

## 接口分组

统一在 `/secondhand/api/...` 下：

- `auth`：注册、登录、当前用户
- `goods`：列表、详情、发布、更新、下架
- `cart`：列表、添加、修改数量、删除
- `order`：创建、支付、取消、确认收货、我的订单
- `favorite` / `chat` / `report` / `upload`
- `admin`、`admin_manage`：审核、用户、举报、统计

## 运行说明

- 数据库：`campus_secondhand`；建表脚本 `sql/create_tables.sql`，升级脚本按 `upgrade_*.sql` 顺序执行
- Redis 可选：未启动时风控自动降级为放行，不影响主流程
- 定时任务：聚合入口启动时注册超时关单任务（扫描未支付订单并自动取消）
- 测试账号：`test001 / 123456`（见 `sql/seed_test_data.sql`）
- 入口页面：`/secondhand/static/index.html`
