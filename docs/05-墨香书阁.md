# 05 · 墨香书阁（图书借阅管理）

> 带书籍封面与阅读成就体系的图书管理平台。借阅库存联动、筛选分页、CSV 导出，以及答题完书验证与成就徽章。

- **前缀**：`/book/`
- **代码位置**：`apps/book/`
- **技术栈**：FastAPI · Pydantic · JSON 文件存储（线程安全读写）· 原生 HTML/CSS/JS · 无需数据库

## 功能模块

| 模块 | 说明 |
|------|------|
| 图书管理 | 新增 / 编辑 / 删除，书名、作者、分类、简介、封面 |
| 借阅归还 | 借出与归还，库存数量实时联动，借阅记录留痕 |
| 检索筛选 | 关键词搜索、分类筛选、分页 |
| 导出 | 图书与借阅记录 CSV 导出 |
| 完书答题 | 完成阅读后答题校验，通过计入完书记录 |
| 成就体系 | 十枚成就徽章，按阅读数量与完成度解锁 |
| 封面库 | 15 张书籍封面静态资源 |

## 目录结构

```
apps/book/
├── main.py             # 入口与接口
├── book_models.py      # 图书 / 借阅 / 答题 / 成就数据模型
├── book_storage.py     # JSON 存储层（原子写 + 文件锁）
├── data/               # books / borrows / quizzes / completions / achievement_state
├── static/
│   ├── index.html      # 单页界面
│   └── covers/         # 15 张书籍封面
├── generate_covers.py  # 封面资源生成脚本
└── requirements.txt
```

## 接口分组

统一在 `/book/api/...` 下：

- `books`：列表（搜索 / 分类 / 分页）、详情、新增、更新、删除
- `borrow`：借出、归还、借阅记录
- `quiz`：题目获取、答案提交、完书记录
- `achievements`：成就状态、解锁判定
- `export`：图书 / 借阅记录导出

## 运行说明

- 无数据库依赖，数据保存在 `apps/book/data/*.json`，首次启动自动创建
- 写入采用临时文件替换，避免并发写入损坏
- 入口页面：`/book/`
