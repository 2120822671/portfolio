# 招财记账 v2.0 · 使用说明

## 快速开始

1. 双击 `start.bat`（首次会自动安装缺失依赖）
2. 浏览器自动打开 **http://localhost:8005/** —— 页面由后端托管，和接口同源，最稳定
3. 顶部选账本 → 记一笔账，或点右下角招财猫直接说「午饭 30」

> 也可以直接双击 `index.html` 打开（`file://` 方式同样可用）。
> 但**推荐用 http://localhost:8005/**：同源访问不会有任何跨域拦截问题，
> 在预览面板、iframe、编辑器内嵌等环境下都能正常工作。

### 如果页面提示"连不上后端服务"

说明后端没启动。双击 `start.bat`，或手动执行 `python main.py`，
确认命令行窗口里出现 `Uvicorn running on http://0.0.0.0:8005`。

## 三个标签页

### 📝 记账

| 元素 | 用法 |
| --- | --- |
| 概览卡 | 当前账本今日收入/支出/结余，实时刷新 |
| 快捷金额 | 点 10/20/30/50/100 直接填金额，「清空」清空输入框 |
| 常用分类 | 点分类自动填入；点「💰 工资」还会自动切成收入 |
| 招财猫 | 圆润呆萌造型：左手举「招财」钱袋、右手握小金锤、红围巾、大脚掌，两只手会独立摆动 | 点不同部位有不同反应：摸头、撸肚、握钱袋、敲锤、踩脚掌；点「💬 跟猫说流水」用文字记账 |
| 木鱼 | 敲一下攒功德，音效与飘字都是实时合成的 |
| 流水列表 | 点行打开抽屉，可查看/编辑/删除 |

### 📊 看板

- **本月支出分类占比**：饼图 + 图例，按当前账本统计
- **近 6 个月收支趋势**：双折线（红=支出，绿=收入）
- **近 7 日支出**：柱状图
- **预算与超支预警**：点「＋ 设预算」按分类设月度上限，≥80% 变黄，超支变红并进消息中心
- **记账打卡与成就**：连续天数、打卡天数、5 枚成就徽章
- **月度账单解读**：点按钮让招财猫讲讲这个月花得怎么样
- **我的账本**：新建/切换/删除账本。删除账本时流水会转移到默认账本，**不会丢数据**

### ⚙️ 自动化

- **周期账单自动入账**：房租、订阅、工资设一次就够
  - 点「＋ 新建周期账单」按提示填写
  - 周期可选 `daily`（每天）/ `weekly`（每周）/ `monthly`（每月）
  - 「自动入账」= 1 时系统自动写账；= 0 时只生成待确认提醒
  - 点「▶ 立即检查并执行」可手动触发一次
- **自动任务与调度状态**：显示时区、大模型是否启用、三个任务的下次执行时间
- **日报与消息中心**：每天 23:00 生成收支小结、23:10 生成消费复盘，预算超支立即预警

## 招财猫能听懂什么

| 你说 | 它会做 |
| --- | --- |
| `午饭 30` | 弹出确认卡，确认后入账 |
| `工资 8000` | 识别为收入 |
| `昨天打车15` | 自动填昨天的时间 |
| `今天花了多少` | 播报当前账本今日收支 |
| `分析一下我的消费` | 生成当日消费点评与省钱建议 |
| `再来一笔20` | 沿用上一笔的分类 |

> 所有记账都必须经过确认卡才会入库，不会直接扣钱。

## 配置大模型（可选）

不配置也能完整使用（走规则解析）。配置后招财猫能处理更复杂的语句、多笔拆分、生成更自然的点评。

**方式一：命令行临时设置**
```bash
set LLM_API_KEY=你的Key
set LLM_BASE_URL=https://api.deepseek.com/v1
set LLM_MODEL=deepseek-chat
python main.py
```

**方式二：PowerShell 永久设置**
```powershell
[Environment]::SetEnvironmentVariable("LLM_API_KEY", "你的Key", "User")
```

**方式三：Windows 图形界面**
`此电脑 → 右键属性 → 高级系统设置 → 环境变量 → 新建`

支持的变量：

| 变量 | 说明 | 默认值 |
| --- | --- | --- |
| `LLM_API_KEY` | API Key，不填则全程规则模式 | 空 |
| `LLM_BASE_URL` | OpenAI 兼容接口地址 | `https://api.deepseek.com/v1` |
| `LLM_MODEL` | 模型名 | `deepseek-chat` |

> 接口按 OpenAI 兼容的 `/chat/completions` 规范实现，换服务商请对照其官方文档核对地址与模型名。

## 常见问题

### Q1：页面提示"接口请求失败，请确认后端是否启动"
后端没起来。双击 `start.bat` 启动，或手动执行 `python main.py`。注意看那个最小化的命令行窗口有没有报错。

### Q2：点"生成账单解读"提示大模型未配置
正常。没配 `LLM_API_KEY` 时系统走规则引擎生成解读，功能可用，只是文案没那么灵动。

### Q3：周期账单没有按时入账
打开「⚙️ 自动化 → 自动任务与调度状态」确认后端在运行（调度器随后端启停）。再检查规则的 `startDate` 是否包含目标日期、`cycleType` 是否匹配。

### Q4：怎么知道重复触发会不会产生重复账？
「立即检查并执行」连点两次，第二次会显示「跳过」，不会重复入账。这是幂等设计的验证方式。

### Q5：删账本会不会丢流水？
不会。删账本时该账本下的流水自动转移到默认账本（日常账本），界面上也会提示迁移了多少笔。

### Q6：数据库密码改了会不会影响已有数据？
改的是连接配置，不影响数据内容。但如果连不上数据库，页面会加载失败。

## 出错了怎么办

| 现象 | 可能原因 | 排查步骤 |
| --- | --- | --- |
| 后端启动即退出 | 依赖缺失 | 运行 `pip install fastapi uvicorn pymysql apscheduler requests` |
| 报 `Access denied` | 数据库密码错 | 检查 `db.py` 的 `DB_CONFIG` 或环境变量 `DB_PASSWORD` |
| 报 `Unknown database` | 库不存在 | 执行 `建表SQL.sql`，或直接跑 `python db.py`（会自动建库表） |
| 端口 8005 被占用 | 旧进程没退 | 任务管理器结束 `python.exe`，或改 `main.py` 里的端口 |
| 日报不生成 | 后端没常驻 / 已到定时点未触发 | 用「立即生成日终汇总」手动触发验证；调度器需要后端持续运行 |
| 图表空白 | 当前账本本月无数据 | 换账本，或先记几笔账 |
