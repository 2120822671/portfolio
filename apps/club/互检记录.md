## 三、优化建议（1 条）

### 建议：添加 .env 配置文件管理敏感信息

**当前问题**：
数据库密码直接写在 main.py 中，提交到 Gitee 会泄露。

**优化方案**：
1. 创建 `.env` 文件存储敏感配置：
```env
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=你的实际密码
DB_NAME=club_activity
```

2. 修改 main.py 读取环境变量：
```python
from dotenv import load_dotenv
import os

load_dotenv()

DB_CONFIG = {
    "host": os.getenv("DB_HOST", "localhost"),
    "port": int(os.getenv("DB_PORT", 3306)),
    "user": os.getenv("DB_USER", "root"),
    "password": os.getenv("DB_PASSWORD"),
    "database": os.getenv("DB_NAME", "club_activity"),
    "charset": "utf8mb4",
    "cursorclass": pymysql.cursors.DictCursor,
}
```

3. 在 `.gitignore` 中添加 `.env`，防止提交到仓库。

**好处**：
- 密码不会泄露到代码仓库
- 不同环境（开发/生产）可配置不同密码
- 符合安全最佳实践
